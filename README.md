\# Описание работы программ (Лабораторная работа)



В данном репозитории содержатся три скрипта на языке Python, решающие базовые задачи по управлению потоком вычислений, циклам и ветвлениям.



\## 1. Вывод диапазона чисел (`range\_numbers.py`)

Программа принимает на вход два целых числа \\(a\\) и \\(b\\) и выводит все числа между ними включительно в одну строку.



\### Как это работает:

\- Если \\(a < b\\), программа использует цикл `for` с шагом `1` для последовательного вывода чисел по возрастанию.

\- Если \\(a > b\\), цикл `for` запускается с отрицательным шагом `-1`, выводя числа по убыванию.

\- Если \\(a = b\\), условие проверяет равенство и выводит ровно одно число.



\---



\## 2. Статистика потока чисел (`statistics.py`)

Программа анализирует последовательность из \\(n\\) целых чисел для поиска минимального, максимального и среднего значения без использования списков (массивов).



\### Как это работает:

\- Сначала пользователь вводит количество элементов \\(n\\) (где \\(n \\ge 1\\)).

\- Чтобы избежать логической ошибки (например, когда инициализация минимума или максимума нулем ломает логику при работе с отрицательными числами), программа сразу запрашивает \*\*самое первое число\*\*. 

\- Переменные `minimum`, `maximum` и `total\_sum` инициализируются значением этого первого числа.

\- В цикле от 2 до \\(n\\) программа считывает оставшиеся числа, на лету обновляя экстремумы и накапливая общую сумму.

\- В конце вычисляется среднее арифметическое и результат выводится на экран.



\---



\## 3. Фильтрация ввода (`positive\_input.py`)

Программа требует от пользователя ввести строго положительное число (больше 0), подсчитывая количество неудачных попыток.



\### Как это работает:

\- Программа запускает бесконечный цикл `while True`.

\- На каждой итерации увеличивается счетчик отклонённых вводов, если введенное число меньше или равно нулю.

\- Как только вводится число \\(> 0\\), оператор `break` прерывает цикл.

\- Программа выводит квадрат успешно введенного числа и итоговое количество некорректных попыток.

\- \*Примечание:\* По условию гарантируется ввод корректных целых чисел (тип `int`), обработка текстовых исключений здесь не требуется.
